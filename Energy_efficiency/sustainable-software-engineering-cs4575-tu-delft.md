## Descriptive Metadata

- **`name`** Sustainable Software Engineering (CS4575)
- **`description`** A TU Delft MSc course on sustainable software engineering, covering environmental, social, and individual sustainability across the software lifecycle, with a strong Green Software Engineering component on measuring and improving energy efficiency. All lecture slides, schedule, and course materials are published openly on GitHub under an MIT licence.
- **`abstract`** Sustainable Software Engineering is an overarching discipline that addresses the long-term consequences of designing, building, and releasing a software project. The course covers a set of competencies needed to leverage sustainable software systems, with a strong component on Green Software Engineering covering techniques to measure and improve energy efficiency at any stage of the software lifecycle, alongside core principles of empirical software engineering and social/individual sustainability.

## Audience & Prerequisites

**`audience`** (Audience)
- **`audienceType`** Students of the MSc Computer Science and the MSc Data Science and Artificial Intelligence Technology programmes at TU Delft; openly usable by any self-learner via the published GitHub materials

**`competencyRequired`**
- Intermediate understanding of object-oriented programming languages
- Basic understanding of data analysis techniques

**`teaches`**
- Explain the fundamental sustainability principles and their relevance to software engineering
- Assess the energy consumption of software systems using measurement and testing techniques
- Create actionable strategies to address sustainability issues within software organisations
- Evaluate solutions for sustainable software systems based on their effectiveness and stakeholder impact
