## Descriptive Metadata

- **`name`** MIT 6.5940 TinyML and Efficient Deep Learning Computing
- **`description`** This course focuses on efficient machine learning and systems, introducing techniques that enable powerful deep learning applications on resource-constrained devices.
- **`abstract`** Topics include model compression, pruning, quantization, neural architecture search, distributed training, data/model parallelism, gradient compression, and on-device fine-tuning, plus application-specific acceleration for large language models and diffusion models. Students get hands-on experience implementing model compression techniques and deploying LLMs (Llama2-7B) on a laptop.
- **`keywords`** TinyML, model compression, pruning, quantization, neural architecture search, distributed training, LLM inference, efficient deep learning
