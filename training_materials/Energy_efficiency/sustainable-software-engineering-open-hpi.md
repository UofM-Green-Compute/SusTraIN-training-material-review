## Descriptive Metadata

- **`name`** Sustainable Software Engineering
- **`description`** A free, self-paced two-week openHPI course on resource-efficient software engineering, covering climate-friendly decisions across the software development lifecycle with a practical, Python-based second half on writing resource-efficient code.
- **`abstract`** The course opens by examining the ecological footprint of digitization — how IT both helps reduce CO2 and contributes to it — and surveys the roles common in the IT industry (developer, IT architect, team lead) to identify where each role can act on resource efficiency. The second week covers the barriers that hinder more ecological action in software development and concrete solutions a developer can apply, using Python for the hands-on material because it is widely known, not because it is a particularly efficient language.
- **`keywords`** sustainable software engineering, green software, resource efficiency, Python, ecological footprint, climate-friendly software development, digitization and CO2

## Audience & Prerequisites

**`audience`** (Audience)
- **`audienceType`** Software Developers, Software Architects, Product Owners, and anyone interested in sustainable software engineering

**`competencyRequired`**
- General IT knowledge
- Solid mathematical knowledge
- Basic knowledge of programming in Python

**`teaches`**
- Understand the ecological footprint of digitization, including how IT both helps reduce and contributes to CO2 emissions
- Identify opportunities for resource-efficient action across common IT industry roles (developer, IT architect, team lead)
- Recognize the barriers that hinder more ecological action in software development and how to overcome them
- Apply concrete, hands-on techniques (in Python) to develop software in a more climate-friendly way
